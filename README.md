# MCP Student Dashboard 🎓

A simple and interactive Student Dashboard built using **FastMCP** and **Prefab UI**. This project demonstrates how to create an MCP tool with a user-friendly dashboard interface.

## 🚀 Features

- Interactive Student Dashboard
- Built using FastMCP
- User interface powered by Prefab UI
- Displays student information
- Simple and lightweight project structure

## 🛠️ Technologies Used

- Python
- FastMCP
- Prefab UI
- UV – Python package and project manager

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Immanuelimman123/MCP-Student-Dashboard.git
```

### 2. Navigate to the Project Directory

```bash
cd MCP-Student-Dashboard
```

### 3. Create a Virtual Environment and Install Dependencies

```bash
uv sync
```

### 4. Run the MCP Server

```bash
uv run server.py
```

The MCP server will start using the STDIO transport.
